# Roadmap

## Phase 1 — current

- FastAPI job API
- filesystem worker
- one-sentence CLI
- MiniMax H3 OpenAI-compatible planner adapter
- TTS interface with offline fallback
- deterministic SRT and FFmpeg vertical MP4
- versioned Story Plan contract

## Phase 2

- Redis/Postgres job backend
- retry policy and idempotency keys
- Web dashboard for history, usage, failed jobs and artifacts
- structured provider usage/cost records
- container image and local compose stack

## Phase 3

- Character Library and Asset Library
- image/video hosted providers
- reference image management
- template versioning and brand presets
- provider capability discovery

## Phase 4

- MCP Server
- Claude Code, Codex and Kimi Code tools
- Article-to-video GitHub Action
- blog/WeChat/Bilibili/Xiaohongshu publishing workflows
- human review and approval gates before external publishing
